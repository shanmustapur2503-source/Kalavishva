# Kalavishva React Website

Frontend-only React/Vite website for Kalavishva — crafted with soul.

## Run

```bash
npm install
npm run dev
```

## Main configuration

Edit:

`src/data.js`

You can change:
- Brand name
- Tagline
- Logo
- Email
- Phone / WhatsApp
- Navigation
- Announcement
- Hero slider
- Story section
- Categories
- Products
- Prices
- Product images
- Google Form URL
- Google Form entry IDs
- About section
- Footer

## Images

## Google Form

Replace `formUrl` and the `entry.xxxxx` IDs in `src/data.js` with your real Google Form details.

The cart builds order details and total amount into the Google Form URL.

## Important

No backend or database is included.

The website uses a luxury professional palette: Deep Forest Green, Champagne Gold, Warm Ivory, White, Charcoal and Slate Gray.
